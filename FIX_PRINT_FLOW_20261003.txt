แก้ไข 03/10/2026

1) หน้าดำเนินงาน
- เอา dropdown เลือกสถานะออก เพื่อไม่ให้เกิดข้อความ Please select an item in the list
- ตอนกำลังดำเนินการ แสดงปุ่ม เปิดหน้าพิมพ์งาน / พิมพ์เสร็จ พร้อมรับงาน / ยกเลิกงาน
- ตอนพร้อมรับ แสดงปุ่ม ลูกค้ารับงานแล้ว / เสร็จสิ้น

2) หน้าพิมพ์งาน
- เวลาสั่งพิมพ์ จะพิมพ์เฉพาะไฟล์ลูกค้า ไม่พิมพ์ข้อมูลเลขคิว ราคา หรือรายละเอียดคำสั่งงาน
- รูปภาพจะตั้งหน้ากระดาษ A4/A3 ตามรายการ และเลือกแนวตั้ง/แนวนอนตามรูปอัตโนมัติ
- จำนวนชุดของไฟล์รูปภาพจะถูกทำซ้ำตามจำนวนชุดที่ร้านยืนยัน
- เพิ่มคำเตือนให้ตรวจ Color/Black and white และเครื่องพิมพ์ในหน้าต่าง Print เพราะ browser ไม่สามารถบังคับค่าของ printer driver ได้
- PDF ให้เปิดไฟล์ต้นฉบับแล้วพิมพ์จาก PDF โดยตรง เพื่อรักษาจำนวนหน้าและขนาดเอกสาร
