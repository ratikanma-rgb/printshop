อัปเดต 03/10/2026

1. แก้ปัญหา 419 Page Expired ตอนเข้าสู่ระบบ
   - ใช้ session cookie เฉพาะของ PrintShop
   - ถ้า session หมดอายุ ระบบจะกลับหน้าเข้าสู่ระบบพร้อมข้อความแจ้ง แทนหน้า 419 เปล่า ๆ
   - START_PRINTSHOP.bat จะปิด PHP server เก่าที่ค้างบน port 8000 ก่อน เพื่อไม่ให้เปิดโปรเจกต์คนละชุด

2. ปรับคำในหน้าลูกค้าและพนักงานให้สั้นและเป็นภาษาที่ใช้ทั่วไป
   - ยืนยันราคา
   - ส่งงานให้ร้านตรวจ
   - แจ้งการชำระเงิน
   - ไม่อนุมัติ / ให้ลูกค้าแก้ไข
   - หลักฐานการชำระเงิน

3. ลำดับงานยังคงเป็น
   ลูกค้าส่งงาน -> ร้านตรวจไฟล์และยืนยันราคา -> ลูกค้าชำระเงิน -> ร้านตรวจการชำระเงิน -> เริ่มพิมพ์
